# 🤖 RDX Escrow Bot

**Developer:** @clerkMM  
**Service:** RDX Escrow Service

A complete Telegram escrow bot with all moderation features (similar to @missrose_bot).

## ✨ Features
- 🔒 Escrow transactions with 3% fee
- 📊 Admin panel with full control
- 🛡️ Full moderation commands (ban, mute, warn, purge, antiflood, antilink)
- 👋 Welcome/Goodbye messages
- 📝 Notes & filters
- 🔗 Anti-link protection
- 🚫 Anti-flood system
- ✅ Captcha verification
- 📌 Pin/Unpin messages
- 🐌 Slowmode
- 📢 Broadcast system

## 🚀 Deployment

### Local Setup
```bash
git clone https://github.com/YOUR_USERNAME/RDX-Escrow-Bot.git

# Create .env file with your BOT_TOKEN and OWNER_ID
